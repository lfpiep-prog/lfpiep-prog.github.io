Privacy Policy

The Hook Room Pipeline is a private tool used only by its operator for the operator's own YouTube channels.

Data accessed

  • Upload videos to the operator's own channels (YouTube Data API, scope youtube.upload).
  • Read channel and video information of the operator's own channels (youtube.readonly).
  • Read analytics of the operator's own channels (yt-analytics.readonly).

How data is used and stored

  • Data is used only to upload the operator's own videos and to evaluate how they perform.
  • Access tokens and statistics are stored only on the operator's own computer. There is no server and no database.
  • No data is sold, shared with third parties, or used for advertising.
  • The use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

This tool uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.
